I. Le HTML

HTML signifie HyperText Markup Language. Il permet de créer la structure et le contenu d'une page web.

Ce qu'il faut connaître

  1. La structure d'un document HTML
  2. Les balises
  3. Les attributs
  4. La structuration d'une page

1. La structure d'un document HTML

Un document HTML est composé de plusieurs balises. Chaque balise possède un rôle précis.

  • html : contient toute la page.
  • head : contient les informations de la page.
  • body : contient les éléments visibles.
<!DOCTYPE html>
<html>

<head>
    <title>Ma page</title>
</head>

<body>
    <h1>Bonjour</h1>
</body>

</html>

2. Les balises

Les balises permettent de donner une structure au contenu d'une page web.

  • h1 à h6 : les titres.
  • p : les paragraphes.
  • a : les liens.
  • img : les images.
  • ul : liste non ordonnée.
  • ol : liste ordonnée.
  • li : élément d'une liste.
  • header : en-tête.
  • nav : navigation.
  • main : contenu principal.
  • section : partie de la page.
  • footer : pied de page.
<h2>Mon titre</h2>

<p>Mon paragraphe</p>

<a href="https://example.com">
    Mon lien
</a>

3. Les attributs

Les attributs donnent des informations supplémentaires aux balises HTML.

  • id : identifie un élément.
  • class : donne une classe.
  • href : destination d'un lien.
  • src : source d'une image.
  • alt : description d'une image.
  • title : information au survol.
  • width : largeur.
  • height : hauteur.
<p class="texte" id="premier">
    Bonjour
</p>

II. HTML avancé

Après les bases, HTML permet également de créer des structures plus complètes et des pages mieux organisées.

1. Les balises sémantiques

Les balises sémantiques permettent de donner un sens aux différentes parties d'une page. 

<header>
    En-tête
</header>

<nav>
    Navigation
</nav>

<main>

    <section>
        Contenu
    </section>

    <article>
        Article
    </article>

</main>

<footer>
    Pied de page
</footer>

2. Les formulaires

Les formulaires permettent de récupérer des informations saisies par l'utilisateur. 

<form>

    <label>Nom :</label>

    <input type="text" required>

    <label>Email :</label>

    <input type="email" required>

    <button type="submit">
        Envoyer
    </button>

</form>

3. Les tableaux

Les tableaux permettent d'organiser des informations sous forme de lignes et de colonnes. 

<table>

    <tr>
        <th>Nom</th>
        <th>Âge</th>
    </tr>

    <tr>
        <td>Yves</td>
        <td>17</td>
    </tr>

</table>

4. Audio et vidéo

HTML permet également d'intégrer directement des fichiers audio et vidéo. 

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
</audio>

<video controls width="500">
    <source src="video.mp4" type="video/mp4">
</video>

5. Attributs utiles

required

Rend un champ obligatoire.

placeholder

Affiche un texte indicatif.

autocomplete

Facilite la saisie.

minlength

Définit une longueur minimale.

III. Le CSS

CSS signifie Cascading Style Sheets. Il permet de modifier l'apparence d'une page HTML.

1. Les sélecteurs

p {
    color: blue;
}

h1 {
    text-align: center;
}

2. Les classes

.texte {
    color: blue;
}

3. Les identifiants

#p2 {
    color: black;
}

4. Les couleurs

p {
    color: blue;
    background-color: white;
}

5. La taille et la police

h1 {
    font-size: 50px;
}

body {
    font-family: Arial, sans-serif;
}

6. Les bordures

main {
    border: 3px solid black;
}

7. Margin et Padding

section {
    margin: 20px;
    padding: 20px;
}

IV. CSS avancé

CSS possède plusieurs fonctionnalités permettant de créer des interfaces modernes et organisées.

1. Flexbox

Flexbox permet d'aligner et d'organiser facilement plusieurs éléments sur une ligne ou une colonne. 

.conteneur {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

3. Responsive Design

Le responsive permet à une page de s'adapter aux différentes tailles d'écran.

Une page peut être adaptée aux ordinateurs, tablettes et téléphones. 

@media (max-width: 600px) {

    .conteneur {
        flex-direction: column;
    }

}

4. Les unités CSS

px

Unité fixe.

%

Pourcentage de l'élément parent.

vw

Pourcentage de la largeur de l'écran.

vh

Pourcentage de la hauteur de l'écran.

5. Les animations

Les animations CSS permettent de modifier progressivement l'apparence ou la position d'un élément. 

@keyframes mouvement {

    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(100px);
    }

}

.element {
    animation: mouvement 2s infinite;
}
Animation CSS

6. Transform

La propriété transform permet de déplacer, agrandir, réduire ou faire pivoter un élément. 

.element:hover {
    transform: scale(1.1);
}

7. Positionnement

CSS permet également de contrôler la position des éléments avec la propriété position. 

.element {
    position: relative;
}

.element2 {
    position: absolute;
    top: 20px;
    left: 20px;
}

8. Pseudo-classes

Les pseudo-classes permettent d'appliquer un style selon l'état d'un élément. 

a:hover {
    color: red;
}

input:focus {
    border: 2px solid blue;
}

9. Variables CSS

Les variables permettent de stocker des valeurs que l'on peut réutiliser dans plusieurs endroits. 

:root {
    --couleur-principale: darkblue;
}

h1 {
    color: var(--couleur-principale);
}

À retenir

Flexbox permet principalement d'organiser les éléments sur un axe.

Grid permet de créer des mises en page avec lignes et colonnes.

Responsive permet d'adapter le site aux différentes tailles d'écran.

Animation permet de créer des mouvements avec CSS.
