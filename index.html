I. Le HTML

HTML signifie HyperText Markup Language. Il permet de créer la structure et le contenu d'une page web.

Ce qu'il faut connaître

  1. La structure d'un document HTML
  2. Les balises
  3. Les attributs
  4. La structuration d'une page web

1. La structure d'un code HTML

Un document HTML est composé de balises. Chaque balise possède un rôle précis.

  • html : contient toute la page.
  • head : contient les informations de la page.
  • body : contient les éléments visibles.

Exemple :

<!DOCTYPE html>
<html>

<head>
    <title>Ma page</title>
</head>

<body>
    <h1>Bonjour</h1>
</body>

</html>

2. Les balises

Les balises permettent de donner une structure au contenu d'une page web.

  • h1 à h6 : les titres.
  • p : les paragraphes.
  • a : les liens.
  • img : les images.
  • ul : une liste non ordonnée.
  • ol : une liste ordonnée.
  • li : un élément de liste.
  • header : l'en-tête.
  • nav : la navigation.
  • main : le contenu principal.
  • section : une partie de la page.
  • footer : le pied de page.

Exemple :

<h2>Mon titre</h2>

<p>Mon paragraphe</p>

<a href="https://example.com">
    Mon lien
</a>

3. Les attributs

Les attributs donnent des informations supplémentaires aux balises HTML.

  • id : identifie un élément.
  • class : donne une classe à un élément.
  • href : indique la destination d'un lien.
  • src : indique la source d'une image.
  • alt : décrit une image.
  • title : affiche une information au survol.
  • width : définit une largeur.
  • height : définit une hauteur.

Exemple :

<p class="texte" id="premier">
    Bonjour
</p>
Class et ID :

Une class peut être utilisée sur plusieurs éléments.

Un id sert généralement à identifier un élément précis.

II. Le CSS

CSS signifie Cascading Style Sheets, ou feuilles de style en cascade.

Il permet de modifier l'apparence d'une page HTML : couleurs, tailles, marges, bordures, positionnement, etc.

1. Qu'est-ce que le CSS ?

HTML sert principalement à structurer la page, tandis que CSS sert à la mettre en forme.

2. Les sélecteurs CSS

Un sélecteur permet de choisir l'élément HTML que l'on souhaite modifier. 

p {
    color: blue;
}

h1 {
    text-align: center;
}

3. Le sélecteur class

Une class est appelée avec un point . en CSS. 

.texte {
    color: blue;
}

4. Le sélecteur id

Un id est appelé avec le symbole # en CSS. 

#p2 {
    color: black;
}

5. Les couleurs

La propriété color permet de modifier la couleur du texte.

La propriété background-color permet de modifier la couleur du fond. 

p {
    color: blue;
    background-color: white;
}

6. La taille du texte

La propriété font-size permet de modifier la taille du texte. 

h1 {
    font-size: 50px;
}

7. La police

La propriété font-family permet de choisir la police du texte. 

body {
    font-family: Arial, Helvetica, sans-serif;
}

8. Les bordures

La propriété border permet d'ajouter une bordure autour d'un élément. 

main {
    border: 3px solid black;
}

9. Les marges et les espaces

margin permet de créer un espace autour d'un élément.

padding permet de créer un espace entre le contenu et la bordure. 

section {
    margin: 20px;
    padding: 20px;
}

10. Quelques propriétés CSS importantes

color

Couleur du texte.

background-color

Couleur du fond.

font-size

Taille du texte.

font-family

Police du texte.

text-align

Alignement du texte.

border

Bordure.

margin

Marge extérieure.

padding

Espace intérieur.

À retenir

HTML construit la structure de la page.

CSS s'occupe de son apparence.

Les deux technologies sont complémentaires.
