HTML CSS

Nous découvrons HTML et CSS à IISAN Abidjan pour la structuration et le design d'une page web. Ce projet est codé en HTML5 et en CSS3.

I. Le HTML

Pour maîtriser HTML, il faut connaître :

  1. La structure d'un code HTML
  2. Les balises
  3. Les attributs des différentes balises
  4. L'utilisation des balises dans la structuration de la page

1. La structure d'un code HTML

Un code HTML est composé de balises et chaque balise a un rôle précis. Une page HTML possède généralement une structure de base.

  • html : contient toute la page.
  • head : contient les informations de la page.
  • body : contient les éléments affichés sur la page.

Exemple :

                
<!DOCTYPE html>
<html>
    <head>
        <title>Ma page</title>
    </head>
    
    <body>
        <h1>Bonjour</h1>
    </body>

 </html>

2. Les balises

Les balises permettent de donner une structure au contenu d'une page web.

  • h1 à h6 : les titres.
  • p : les paragraphes.
  • a : les liens.
  • img : les images.
  • ul : une liste non ordonnée.
  • ol : une liste ordonnée.
  • li : un élément de liste.
  • header : l'en-tête.
  • nav : la zone de navigation.
  • main : le contenu principal.
  • section : une partie de la page.
  • footer : le pied de page.

Exemple :

                
<h2>Mon titre</h2>
<p>Mon paragraphe</p>
<a href="https://example.com">Mon lien</a>

3. Les attributs

Les attributs donnent des informations supplémentaires aux balises.

  • id : permet d'identifier un élément.
  • class : permet de donner une classe à un élément.
  • href : indique la destination d'un lien.
  • src : indique la source d'une image.
  • alt : donne une description d'une image.
  • title : affiche une information au survol.
  • width : définit la largeur.
  • height : définit la hauteur.

Exemple :

                
<p class="texte" id="premier">Bonjour</p>

Une class peut être utilisée sur plusieurs éléments, alors qu'un id sert normalement à identifier un élément précis.

II. Le CSS

Le CSS permet de modifier l'apparence d'une page HTML. Il permet par exemple de changer les couleurs, les tailles, les marges et les bordures.

1. Qu'est-ce que le CSS ?

CSS signifie Cascading Style Sheets, ou feuilles de style en cascade. HTML sert principalement à structurer la page et CSS sert à la mettre en forme.

2. Les sélecteurs CSS

Un sélecteur permet de choisir l'élément HTML que l'on veut modifier. 

                 
                     p {
                        color: blue;
                    }

                    h1 {
                        text-align: center;
                    }

3. Le sélecteur class

Une class est appelée avec un point . en CSS. 

                
                    .texte {
                            color: blue;
                    }

4. Le sélecteur id

Un id est appelé avec le symbole # en CSS. 

                
                    #p2 {
                         color: black;
                    }

5. Les couleurs

La propriété color permet de modifier la couleur du texte. La propriété background-color permet de modifier la couleur de fond. 

                
                    p {
                        color: blue;
                        background-color: white;
                }

6. La taille du texte

La propriété font-size permet de modifier la taille du texte. 

                
                    h1 {
                        font-size: 50px;
                }

7. La police

La propriété font-family permet de choisir la police du texte. 

                
                    body {
                         font-family: Arial, Helvetica, sans-serif;
                    }

8. Les bordures

La propriété border permet d'ajouter une bordure autour d'un élément. 

                
                    main {
                          border: 3px solid black;
                        }

9. Les marges et les espaces

margin permet de créer un espace autour d'un élément. padding permet de créer un espace entre le contenu et la bordure. 

                
                    section {
                            margin: 20px;
                            padding: 20px;
                    }

10. Quelques propriétés CSS importantes

  • color : couleur du texte.
  • background-color : couleur de fond.
  • font-size : taille du texte.
  • font-family : police du texte.
  • text-align : alignement du texte.
  • border : bordure.
  • margin : marge extérieure.
  • padding : espace intérieur.
  • width : largeur.
  • height : hauteur.

Conclusion

HTML et CSS sont deux langages complémentaires. HTML permet de construire la structure d'une page web et CSS permet de modifier son apparence. Leur utilisation permet de créer des pages web simples et organisées.
